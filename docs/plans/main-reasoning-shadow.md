# Main Reasoning Shadow Implementation Plan

> **For Hermes:** Use subagent-driven-development with implementation, spec review, then quality review.

**Goal:** Enable an independent, asynchronous Jev main-effort predictor and private request-example pool without changing live agent reasoning or reviews.

**Architecture:** New standalone `reasoning-shadow` plugin captures immutable pre-run input, recent redacted conversation and identity/timing; enqueues observation without network/database waits on hooks. A bounded worker persists private SQLite/FTS5 examples, makes typed Jev low/high/max predictions from pre-run information only, and associates later execution metadata without treating response/judge pass as verified success. Existing scenario-router and response-critic stay untouched. No tool execution, replay, active routing, global reasoning change or model override.

**Tech stack:** Python 3.11 stdlib SQLite/FTS5/threading/queue; existing httpx and Hermes redactor, PluginManager, ctx.state. Public code in artbred/hermes-plugins; personal data under an active-profile-owned private directory only, never repo/logs/API error output.

## Tasks and acceptance

1. Create `plugins/reasoning-shadow/plugin.yaml`, `__init__.py`, README, tests and a metadata-only CLI/script interface. Modes off/shadow only, default off; parent enables shadow after verification. Resolve profile storage at registration; private directory 0700, DB/WAL/SHM 0600; SQLite bounded retention (2000 examples, 90 days), atomic operations and FTS cleanup. Wrong-mode database is not silently destructive. Synthetic source records must be marked synthetic and excluded by default.
2. Capture pre_llm_call once per real human turn, full redacted request, selected recent conversation (explicit bounded window), model plus monotonic/time and unique session/turn identities. Ignore children, internal notifications, verification continuations and capture duplicates. Queue immutable snapshots with contextvars; missing provenance/identities abstains. Network/FTS/disk work only worker. Overflow/expired/oversized inputs record diagnostics; never change reply or silently classify a truncated request. Every callback returns None, request dictionaries never mutated.
3. SQLite pool keeps source handles, actual model/effort, original request/context, prediction, future outcome/latency/usage/correction and provenance/validation status. Historical import reads state.db read-only, no network, uses deterministic human/turn filtering and a max limit; marks unknown/unverified, not fabricated verified success. Seed requests only before current source timestamp. Existing source records dedupe, without replacing online observations. Annotate is operator-supplied validation only, never inferred from response text or a critic pass.
4. Background typed Decisions call to typesafe/jev-1.13 asks request family, risk, main_effort (low/high/max). Strict shape/labels/probabilities/confidence; technical failures cached persistently with bounded exponential backoff; low confidence falls back high and cannot be marked eligible for live. Prior-example retrieval FTS max5, temporal cutoff excludes current and future turns; mix unknown/failure/success/corrected examples, retain honest status, no success-only selection. Do not send current output/tools/usage/assessment to selector; a deliberate future-outcome marker must never appear in transport. No logs/API bodies/credentials/raw IDs outside private pool. No general external retrieval or embedding service needed.
5. Observer post_api_request captures actual wire effort, token usage, duration without request/response bodies. post_tool_call stores metadata only (counts/errors; no tool args/results). post_llm_call records observed final output privately if needed, duration and unknown verification status. Never claim independent proof or collect hidden chain-of-thought. Correlate parallel turns and compaction only when uniquely safe. No cross-turn/cross-profile metrics mixing; work late after unload cannot write; replay/restore cannot create new duplicate calls. CLI report metadata counts/family/effort/confidence/observed timing, explicitly no low-vs-high speed/quality claims absent controlled replay.
6. Tests first then implementation: causal snapshot isolation, history/cutoff filtering, failure/correction inclusion, FTS Russian/English, strict schemas, no current-outcome transport, nonblocking hooks with provider blocked, bounded queue/retention, cooldown reload/profile isolation, parallel same/missing/rotated IDs, no network in off mode/import/report, late worker unload, real PluginManager registration/dispatch, observed-usage not duplicate count, privacy and secret redaction. Run all existing plugin suites too.
7. Parent performs spec and then quality review, fixes blockers, runs live synthetic/public Jev smoke via real PluginManager in isolated home. Publish allowlisted source/tests/docs only after actual-secret staged scan and verify remote hashes. Install new plugin, enable mode shadow with authenticated human capture and explicit external Jev recommendation (same consent as existing advisor), supported reload readback, verify hooks and private DB records. Seed bounded historical pool with report of exact imported/skipped counts and unknown verification status; never index raw tool bodies or hidden reasoning. Check main model/reasoning and review high/max unchanged, core files unchanged. No active main routing enabled.

**Test command:** `PYTHONPATH=/usr/local/lib/hermes-agent:/usr/local/lib/hermes-agent/venv/lib/python3.11/site-packages /root/.hermes/cache/scratch/jev-active-test-env/bin/python -m pytest plugins/reasoning-shadow/tests plugins/scenario-router/tests plugins/response-critic/tests -o addopts='' -q`

**Not delivered by this phase:** paired low/high replay, proof of low effort correctness/speed, active main reasoning controls, automatic self-training or success-authorizing task shortcuts.
